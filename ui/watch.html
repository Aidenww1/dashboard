Set up Tasker / Health Connect
In Tasker, read aggregated Health Connect data and POST it to /api/health/{type} (steps, totalcalories, sleep, heartrate, distance, floorsclimbed). The endpoint is https://dashboard-pi-green-48.vercel.app/api/health/{type}. See the legacy setup guide for the full step-by-step.
