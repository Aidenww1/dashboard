Security & Privacy
RLS status
events, app_state, health tables — anon role has full access (single-user app). No Supabase Auth. To add per-user scoping: enable Auth and replace anon policies with auth.uid() = user_id checks.
Service role key
Server-only (Vercel env vars). Never exposed to the browser. Anon/publishable key is safe to embed in frontend HTML.
Sensitive data
Bloodwork, skin, supplements stored in Supabase JSONB. No column-level encryption. Protected by Supabase project access keys only. Consider enabling Supabase Auth + RLS for multi-device or shared environments.
Danger Zone
Clear all local data
Wipes localStorage — Supabase backup is NOT deleted
