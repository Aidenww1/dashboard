Setup Guide
  1. Install Tasker and the TaskerHealthConnect plugin (APK from GitHub)
  2. In Samsung Health: Settings → Connected services → Health Connect → enable all data types
  3. In Tasker: create a task using TaskerHealthConnect actions to read steps, heart rate, sleep, calories, weight, SpO2
  4. Add an HTTP Request action: POST to https://dashboard-pi-green-48.vercel.app/api/health-sync with JSON body (see format below)
  5. Schedule the task to run daily or on demand
POST body format:
{ "date": "%DATE", "steps": %steps, "heart_rate_bpm": %hr, "sleep_hours": %sleep_h, "sleep_start_ms": %sleep_start, "sleep_end_ms": %sleep_end, "calories_kcal": %cals, "weight_kg": %weight, "spo2_pct": %spo2 }
