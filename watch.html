Setup Guide
  1. Install Tasker + TaskerHealthConnect plugin (RafhaanShah on GitHub)
  2. Samsung Health → Settings → Connected services → Health Connect → enable all data types
  3. In Tasker: JavaScriptlet sets %start_ts / %end_ts (today midnight to now)
  4. Read Aggregated Data: StepsRecord / COUNT_TOTAL → immediately POST %healthconnectresult to /api/health/steps
  5. Repeat for each metric: TotalCaloriesBurnedRecord/ENERGY_TOTAL → /api/health/totalcalories, SleepSessionRecord/SLEEP_DURATION_TOTAL → /api/health/sleep
  6. Schedule task daily or trigger manually
POST URL: https://dashboard-pi-green-48.vercel.app/api/health/{type}
POST body: paste %healthconnectresult directly. Content-Type: application/json
